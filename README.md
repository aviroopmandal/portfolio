· Computer Vision & Documents: Robust OCR and parsing with Tesseract, OpenCV, and PyMuPDF.

· ML Foundations: PyTorch, TensorFlow, and Scikit-Learn.

· Deployment: Building interfaces and APIs with Gradio, Flask, and SQLite.
